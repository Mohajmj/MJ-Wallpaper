# تحليل MJ V2 والخطة الهندسية

## وظائف MJ V2 (كلها منقولة)
| وظيفة mj-v2.py | مقابلها في التطبيق |
|---|---|
| استيراد فيديو (مجلد الاستيراد) | المكتبة: استيراد من الصور / الملفات |
| مكتبة فيديو + معلومات + حذف | LibraryView + VideoInfoSheet + سحب للحذف |
| إنشاء خلفية (اسم، منع التكرار، تأكيد) | CreateView (يضيف -1 إذا الاسم موجود) |
| تقدم 5 مراحل بنسب 1/10/65/85/97/100 | نفس المراحل والنسب في TendiesBuilder |
| فحص الأرشيف (testzip، المراجع، المفقود) | `ZipReader.testZip` + فحص المراجع |
| تقرير عربي بنفس الصيغة + أرشيف تراكمي JSONL | BuildReport.text + MJ-Reports.jsonl |
| سجل عمليات (ناجحة/فاشلة) + حذف السجل | MJ-History.jsonl + شاشة التقارير |
| إعدادات المسارات | مجلد الحفظ (Security-scoped bookmark) |
| فحص الاعتماديات ffmpeg/ffprobe | **حُذف**: لا حاجة له، المحرك مدمج (AVFoundation) |
| `mj.py` (النسخة القديمة) | للمقارنة فقط، لا وظائف إضافية عنه |

## نقاط مهمة اكتشفتها
1. **الإطارات الفعلية 468×1012 وليس 1013** (تم قياسه في ll.tendies وبإعادة تشغيل أمر ffmpeg الأصلي). تقرير MJ V2 يكتب 1013 لكن مشفّر JPEG يحذف الصف الفردي. المحرك الجديد يطابق الناتج الفعلي (1012) ويكتب 1013 في التقرير كالأصل.
2. المدة: الأصل يأخذها من ffprobe (`format=duration`)؛ التطبيق يأخذها من AVAsset وينسقها بست خانات عشرية مثل ffprobe.
3. القالب Video-B-anim.tendies مدمج بدون أي تعديل (md5 مطابق للأصل).

## قرار المحرك: AVFoundation بدل FFmpeg
- FFmpeg على iOS يحتاج ترجمة معقدة وترخيص LGPL/GPL وحجم كبير؛ AVFoundation مدمج بالنظام، مجاني، ومحلي بالكامل.
- الاختلاف: مقياس الصورة وضغط JPEG مو متطابقين بت-ببت مع ffmpeg. البنية (عدد الإطارات، الأبعاد، المراجع، ملفات الأرشيف) لازم تتطابق وتُفحص آلياً (`tools/compare_outputs.py`). جودة البكسل تنقارن على الجهاز.
- AVFoundation يقرأ MP4/MOV/M4V فقط. **MKV و AVI غير مدعومة** (الأصل كان يقبلها عبر ffmpeg). البديل: تحويلها لـ MP4 قبل الاستيراد، أو دمج FFmpegKit لاحقاً إذا تريد.
